# weavetag

Weave HTML/Markdown tag fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/weavetag/

## Install / run

```bash
git clone https://github.com/theworker02/weavetag.git
cd weavetag
node src/cli.js
node --test
```
